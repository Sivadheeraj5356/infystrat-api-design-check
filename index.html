API Design Check

Public infrastructure APIs get consumed for years by systems you will never meet. Paste endpoints, one per line as METHOD | /path | note(optional), and the check flags identifier leaks in URLs, missing version prefixes, verb-in-path RPC drift, unpaginated collections, missing idempotency hints and naming drift. Heuristic review, not an architecture review.
